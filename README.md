# Naming scheme


| Category / Type of the os |Tag | Theme/Meaning| Username|
|-------------------------|--------------|----------------------------------------|-----------------------|
| Personal GUI Devices| `kami` | Goddesses / divine beings| `offspring`|
| Local Servers | `villainess` | Anime villainess characters| `lastname` |
| AWS Machines| `shou` | Summoned spirits (Fate-style Servants)| `class`|
| Azure Machines| `seirei` | Spirits (Fate-style / ethereal beings)| `class`|

| Category|Tag | Theme/Meaning|
|--------|----------------------------------------|-----------------------|
| Kubernetes Nodes| `senkan:{faction}` | Battleships (KanColle / Azur Lane) |
| Kubernetes Controllers|  `shikikan:{faction}`  |  |  
| architucture |  `arch:{name}`  | architeture of machine defaults to `x86_64` |
| region |  `region:{name}`  | region of the cloud  defaults to `Germany` |
