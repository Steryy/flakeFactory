# Naming scheme

Meta tags they are assigned on directory where host belongs `senkan` needs to have additionally tag related to on which cloud it belongs to

| Category|Tag | Theme/Meaning| Username|
|-------------------------|--------------|----------------------------------------|-----------------------|
| Personal GUI Devices| `kami` | Goddesses / divine beings| `offspring`|
| Kubernetes Nodes| `senkan` | Battleships (KanColle / Azur Lane)| `class` |
| Local Servers | `villainess` | Anime villainess characters| `lastname` |
| AWS Machines| `shou` | Summoned spirits (Fate-style Servants)| `class`|
| Azure Machines| `seirei` | Spirits (Fate-style / ethereal beings)| `class`|
